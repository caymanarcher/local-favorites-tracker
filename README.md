# local-favorites-tracker
This project was built for tracking and organizing my favorite coffee shops, restaurants, and dessert places around Fort Worth. It rates each place and includes a description so people, including me, can explore new places or return to old ones! I used JavaScript, CSS, and HTML to build this website, and it lives at https://caymanarcher.github.io/local-favorites-tracker/. Thank you for using my favorites tracker!
